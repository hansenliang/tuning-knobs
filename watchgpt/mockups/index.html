WatchGPT · codename · watchOS 26+ · design v0.1

Raise, talk, hear the answer. No phone.

Two modes and one tap. Push-to-talk turns run over plain HTTPS, so they work on every cellular watch. Live mode opens a realtime voice session. Every reply is short, spoken, and captioned for a 46 mm screen.

POST /v1/turns · NDJSONWSS /v1/live · PCM16 24 kHzamber = the app's tint

Ask

The core loop, from wrist raise to spoken answer in about 2 seconds. It works over Wi-Fi or LTE with no iPhone in range. The mic button is the whole home screen.

Live

A hands-free conversation for walks, cooking and driving. The server detects when you stop talking, and you can interrupt it at any time. It's metered in minutes, so the remaining time is always on screen.

Trust & edges

Screens that App Review and real-world connectivity require. Consent names each AI provider before the first request (Guideline 5.1.2(i)). There is no login; the subscription is the account.

Getting in fast

The app wins or loses on time-to-mic. Every entry point lands in Listening, not on a menu.

Voice first, glance second

Replies default to 1–3 sentences with no markdown. Text is a caption of what's being spoken, not a document to read.

One color means "yours"

Amber marks what the user can act on and what the assistant is doing. Everything else stays neutral, so it reads in sunlight at a glance.

Codename only

"GPT" in an app name gets rejected (watchGPT had to become Petey in 2023). Pick the ship name before the App Store submission.
